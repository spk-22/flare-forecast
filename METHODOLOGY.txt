1. SCIENTIFIC OBJECTIVE & PROBLEM FORMULATION
--------------------------------------------------------------------------------
1.1 Physical Motivation:
Solar flares are explosive magnetic reconnection events in the solar atmosphere 
releasing up to 10^25 to 10^32 Joules of energy across the electromagnetic spectrum. 
The Mg II h chromospheric emission line (280.3 nm) observed by the Solar Ultraviolet 
Imaging Telescope (SUIT) aboard India's Aditya-L1 spacecraft captures critical 
thermal and dynamic precursors in the upper photosphere and middle chromosphere, 
such as localized flux emergence, pre-flare brightenings, and filament activation.

1.2 Mathematical Formulation of the Prediction Task:
Given a temporal observation window of T consecutive frames:
    X = [x_1, x_2, ..., x_T]^T in R^{T x D}
where T = 80 frames (representing approximately 80 to 90 minutes of continuous 
cadence) and D is the number of active physical features extracted per frame.

Let t_last = timestamp(x_T) be the observation epoch of the most recent frame.
The target is a binary classification label y in {0, 1}:
    y = 1  if a solar flare onset occurs in the temporal horizon:
           0 < (t_flare_start - t_last) <= tau
           where tau = 90 seconds.
    y = 0  if no solar flare begins within tau seconds (and no active ongoing flare).

Here, t_flare_start is defined strictly as the NOAA GOES XRS flare start time 
(initial flux inflection), NOT the flare peak time.

3. MORPHOLOGICAL & PHYSICAL FEATURE EXTRACTION PIPELINE
--------------------------------------------------------------------------------
For every valid FITS file, raw 2D pixel intensities I(x, y) are extracted. Valid 
finite pixels are isolated:
    Omega = {(x, y) | I(x, y) is finite and not NaN}
    N = |Omega|

From Omega, an initial vector of 19 physical, statistical, and astrometric features 
is computed:

  [1] Mean Digital Number (mean_dn):
      mu = (1 / N) * sum_{(x,y) in Omega} I(x, y)

  [2] Standard Deviation (std_dn):
      sigma = sqrt( (1 / N) * sum_{(x,y) in Omega} (I(x, y) - mu)^2 )

  [3] Minimum Intensity (min_dn):
      min_dn = min_{(x,y) in Omega} I(x, y)

  [4] Maximum Intensity (max_dn):
      max_dn = max_{(x,y) in Omega} I(x, y)

  [5-11] Intensity Percentiles (p01, p10, p50, p90, p95, p99, p999):
      P_k = Intensity value such that k% of pixels in Omega fall below P_k.
      Calculated for k in {1.0, 10.0, 50.0 (Median), 90.0, 95.0, 99.0, 99.9}.

  [12] Intensity Skewness (skew_dn):
      gamma_1 = (1 / N) * sum_{(x,y) in Omega} ((I(x, y) - mu) / sigma)^3

  [13] Intensity Fisher Excess Kurtosis (kurt_dn):
      gamma_2 = [ (1 / N) * sum_{(x,y) in Omega} ((I(x, y) - mu) / sigma)^4 ] - 3

  [14] Chromospheric Core Enhancement Ratio (enhancement_ratio):
      R_enh = (P_99 - P_50) / sigma
      Measures localized intense plage/core brightening relative to background variance.

  [15] Bright Pixel Area Fraction (bright_pix_frac):
      f_bright = (1 / N) * sum_{(x,y) in Omega} Indicator( I(x, y) > (P_50 + 2 * sigma) )
      Quantifies spatial expansion of active plage emission regions.

  [16] Header Quality Flag (quality_percent):
      Q_val = float(header['QVAL'])  (Defaults to 100.0)

  [17] Exposure Duration (exposure_s):
      t_exp = float(header['EXPTIME'])

  [18-19] Helioprojective Cartesian (HPC) Centroid Coordinates:
      T_x (arcsec) and T_y (arcsec) representing center of FOV derived via WCS:
      [T_x, T_y] = WCS_pix2world( nx / 2, ny / 2 ) * 3600.0


4. SEQUENCE CONSTRUCTION, SPATIAL TRACKING & LABELLING
--------------------------------------------------------------------------------
4.1 Active Region Spatial Tracking:
Observations are partitioned into physical spatial tracks to prevent mixing 
unrelated solar features across time:
    Track_Key = (obs_id, dim_str, track_roi)
where track_roi is derived from HPC coordinates (tolerance: Delta T <= 300 arcsec).

4.2 Temporal Cadence Verification:
Within each track, frames are chronologically ordered:
    t_1 < t_2 < ... < t_T
A sliding window of length T = 80 frames is advanced with stride s = 1.
To ensure sequence continuity, consecutive frame gaps are verified:
    Delta t_i = t_{i+1} - t_i <= 180 seconds
Any sequence with an irregular observation blackout (Delta t > 180s) is rejected.

4.3 NOAA GOES Ground-Truth Flare Labelling:
Ground-truth flare events are parsed from GOES-16 and GOES-18 XRS catalogs:
  - Flare start time: t_flare_start (UTC)
  - Flare peak time:  t_flare_peak (UTC)
  - Flare end time:   t_flare_end (UTC)
  - Flare GOES class: C, M, or X class flux magnitude

A sequence [x_1, ..., x_80] ending at t_last is labelled:
    y = 1  if exists flare event E such that:
           0 <= (E.t_flare_start - t_last) <= 90 seconds
           AND spatial active region alignment matches.
    y = 0  if no flare occurs in (t_last, t_last + 90s] AND
           t_last does not fall within an active ongoing flare window [E.start, E.end].

4.4 Dataset Scale & Flare Distribution:
  - Total sequences constructed:             2,690 sequences
  - Total positive pre-flare sequences (y=1): 42 sequences
  - Total negative quiet/plage sequences (y=0): 2,648 sequences
  - Positive class prevalence:                1.56% (Extreme Class Imbalance)
  - Independent flare events captured:        32 unique solar flares
  - Flare Magnitude Breakdown:               6 X-Class, 25 M-Class, 11 C-Class


5. EVENT-AWARE CHRONOLOGICAL SPLITTING & DATA INTEGRITY
--------------------------------------------------------------------------------
5.1 Prohibition of Cross-Event Leakage:
A fundamental flaw in naive temporal splitting or random k-fold cross-validation 
is cross-event leakage: if pre-flare frames from the same physical flare event appear 
in both training and test sets, the model achieves artificially inflated scores 
by memorizing the active region's background intensity rather than learning true 
flare precursor signatures.

5.2 Strict Chronological Event Boundary:
The dataset is partitioned chronologically at the split boundary:
    Split Boundary: 2024-12-30 14:00:00 UTC

All flares occurring prior to this timestamp are assigned to Train/Val; all flares 
occurring after are assigned to the Out-Of-Sample Test Set:

  Split Partition    Sequences    Positives (y=1)   Prevalence   Independent Flares
  ---------------------------------------------------------------------------------
  Training Set       1,778        28                1.57%        19 flares
  Validation Set       518         8                1.54%         7 flares
  Test Set             394         6                1.52%         6 flares
  ---------------------------------------------------------------------------------
  Total              2,690        42                1.56%        32 flares

Zero flare events, active regions, or synthetic variations overlap between Train, 
Val, and Test sets.


6. INPUT PREPROCESSING & NORMALIZATION
--------------------------------------------------------------------------------
6.1 Zero-Variance Feature Elimination:
Features are analyzed strictly across the Training Set. Feature 16 (quality_percent) 
exhibited zero variance across the training set (standard deviation < 1e-4, 100% flag). 
It is dropped to prevent degenerate division by zero:
    Active Input Dimensions D = 18 features (out of initial 19).

6.2 Training-Set Z-Score Standardization:
Feature scaling parameters (mean mu_j, standard deviation sigma_j) are calculated 
strictly on the training partition to prevent information leakage:
    mu_j    = (1 / (N_train * T)) * sum_{i=1}^{N_train} sum_{t=1}^T X_{i, t, j}
    sigma_j = sqrt( (1 / (N_train * T)) * sum_{i=1}^{N_train} sum_{t=1}^T (X_{i, t, j} - mu_j)^2 )

If sigma_j < 1e-6, sigma_j is clamped to 1.0.
Every input sequence is normalized and bounded:
    X_norm_{i, t, j} = clip( (X_{i, t, j} - mu_j) / sigma_j, -5.0, 5.0 )
Any potential non-finite values are mapped to 0.0:
    X_norm in R^{B x 80 x 18}


7. DEEP LEARNING MODEL ARCHITECTURES & MATHEMATICAL FORMULATIONS
--------------------------------------------------------------------------------
Three neural network architectures were developed, optimized, and evaluated under 
identical experimental constraints.

================================================================================
7.1 Model 1: Baby Dragon Hatchling v4 (BDH v4 - Primary Proposed Model)
================================================================================
BDH v4 is an advanced temporal convolutional network combining multi-scale causal 
convolutions, dilated gated residual blocks with channel-wise squeeze-and-excitation, 
and temporal attention pooling with a learnable recency bias.

7.1.1 Input Projection:
The 18-dimensional feature vector at each time step t is projected into hidden 
dimension d_h = 64:
    h_0(t) = GELU( LayerNorm( W_in * x_t + b_in ) ),   W_in in R^{64 x 18}

7.1.2 Multi-Scale Causal Convolutions:
To prevent future temporal leakage, all convolutions apply left-sided causal padding:
    Pad_causal(k, d) = (k - 1) * d
Three parallel 1D causal convolutions capture short-, intermediate-, and long-range 
chromospheric evolutions simultaneously:
    c_3(t)  = CausalConv1D(kernel_size=3,  dilation=1, channels=21)(h)
    c_7(t)  = CausalConv1D(kernel_size=7,  dilation=1, channels=21)(h)
    c_15(t) = CausalConv1D(kernel_size=15, dilation=1, channels=22)(h)
    h_ms(t) = GELU( GroupNorm_8( [c_3(t) || c_7(t) || c_15(t)] ) ) in R^{64}

7.1.3 Dilated Gated Residual Blocks with Squeeze-and-Excitation (SE):
A stack of M = 3 residual blocks with exponential dilation rates d in {1, 2, 4}:
For each block l:
    Filter Branch:  f_l = tanh( CausalConv1D_{3, d=2^l}( h_{l-1} ) )
    Gating Branch:  g_l = sigmoid( CausalConv1D_{3, d=2^l}( h_{l-1} ) )
    Gated State:    u_l = Dropout_{0.3}( GroupNorm_8( f_l (x) g_l ) )

Channel Squeeze-and-Excitation:
    s_l = (1 / T) * sum_{t=1}^T u_l(t)  in R^{64}   (Global Average Pooling)
    e_l = sigmoid( W_{se2} * ReLU( W_{se1} * s_l ) ),  where W_{se1} in R^{16 x 64}, W_{se2} in R^{64 x 16}
    Block Output:   h_l(t) = h_{l-1}(t) + u_l(t) (x) e_l

7.1.4 Temporal Positional Attention Pooling with Learnable Recency Bias:
Rather than standard last-step pooling, BDH pools across the entire 80-frame history 
while explicitly weighting the final frames approaching the t_0 flare horizon:
    Let pos(t) = (t - 1) / (T - 1) in [0.0, 1.0]   for t in {1, ..., T}
    Attention Logits:  a(t) = w_attn^T * LayerNorm( h_M(t) ) + beta * pos(t)
    where beta is a learnable scalar parameter initialized to 1.2.
    Attention Weights: alpha(t) = exp( a(t) ) / sum_{t'=1}^T exp( a(t') )
    Pooled Vector:     z = sum_{t=1}^T alpha(t) * h_M(t) in R^{64}

7.1.5 Classification Head:
    z_dense = Dropout_{0.3}( GELU( LayerNorm( W_c1 * z + b_c1 ) ) ),  W_c1 in R^{32 x 64}
    logit   = W_c2 * z_dense + b_c2,                                   W_c2 in R^{1 x 32}
    Probability: P(y = 1 | X) = sigmoid( logit )

Total BDH v4 Trainable Parameters: 119,346 parameters.


================================================================================
7.2 Model 2: LSTM Baseline (Long Short-Term Memory Network)
================================================================================
A standard recurrent temporal baseline designed to evaluate classical recurrent 
state transitions for flare precursor detection.

7.2.1 Architecture:
  1. Input Projection: Linear(18 -> 64) -> LayerNorm -> GELU
  2. Multi-layer LSTM: 2 stacked LSTM layers with hidden dimension d_h = 64, 
     inter-layer dropout = 0.25, batch_first = True.
     [h_1, ..., h_T], (h_T^{(2)}, c_T^{(2)}) = LSTM( h_0 )
  3. Feature Representation: The final temporal hidden state h_T^{(2)} in R^{64} 
     is extracted representing information accumulated up to the prediction horizon.
  4. Classification Head:
     z_dense = Dropout_{0.25}( GELU( LayerNorm( W_1 * h_T^{(2)} + b_1 ) ) ), W_1 in R^{32 x 64}
     logit   = W_2 * z_dense + b_2, W_2 in R^{1 x 32}
     Probability: P(y = 1 | X) = sigmoid( logit )

Total LSTM Trainable Parameters: 70,081 parameters.


================================================================================
7.3 Model 3: Temporal Fusion Transformer (TFT Baseline)
================================================================================
An adapted state-of-the-art transformer architecture for multi-horizon time series, 
incorporating variable selection networks and temporal self-attention.

7.3.1 Architecture Components:
  1. Gated Residual Network (GRN):
     GRN(a, c) = LayerNorm( a + GLU( W_2 * Dropout( ELU( W_1 * a + W_c * c ) ) ) )
     where GLU(x_1 || x_2) = x_1 (x) sigmoid(x_2).
  2. Variable Selection Network (VSN):
     Applies an individual GRN to each of the D = 18 features separately, followed by 
     a softmax gating network across all 18 features to learn dynamic feature importance.
  3. Sequence Processing:
     VSN representations pass through an LSTM encoder (d_h = 64) followed by a 
     post-LSTM GRN.
  4. Interpretable Multi-Head Temporal Self-Attention:
     Multi-head attention with M = 4 heads and d_k = 16:
     Attn(Q, K, V) = softmax( (Q * K^T) / sqrt(d_k) ) * V
     Followed by a post-attention GRN residual connection.
  5. Classifier:
     Final timestep representation passes through a 32-dim LayerNorm MLP to output logit.

Total TFT Trainable Parameters: 237,577 parameters.


8. TRAINING ENGINE & OPTIMIZATION PROTOCOL
--------------------------------------------------------------------------------
8.1 Class-Weighted Binary Cross-Entropy Loss:
Due to the severe class imbalance (positive prevalence = 1.57%), unweighted cross-entropy 
leads to trivial majority-class collapse. Training employs positive-weighted binary 
cross-entropy:
    pos_weight = N_train_negative / N_train_positive = 1750 / 28 = 62.5

    Loss(y, logit) = - (1 / B) * sum_{i=1}^B [ pos_weight * y_i * log( sigmoid(logit_i) ) 
                                               + (1 - y_i) * log( 1 - sigmoid(logit_i) ) ]

8.2 Optimization Hyperparameters:
  - Optimizer:                 AdamW (Loshchilov & Hutter)
  - Base Learning Rate:        eta_0 = 3e-4
  - Weight Decay (L2 penalty): lambda = 1e-4
  - Learning Rate Schedule:    Cosine Annealing over E = 40 epochs:
                               eta_e = eta_min + 0.5 * (eta_0 - eta_min) * (1 + cos(pi * e / E))
                               where eta_min = 1e-5
  - Gradient Norm Clipping:    ||g||_2 <= 3.0 (Prevents gradient explosion during flare spikes)
  - Batch Size:                B = 64
  - Total Training Epochs:     40 epochs per model

8.3 Checkpoint Selection Strategy:
At the conclusion of each epoch e, the model is evaluated on the independent 
Validation Set (518 sequences, 8 positives, 7 flares). Model state_dict checkpoints 
are preserved strictly based on maximizing Validation PR-AUC (Average Precision), 
NOT validation loss or accuracy.


9. QUANTITATIVE BENCHMARK RESULTS & METRIC DEFINITIONS
--------------------------------------------------------------------------------
9.1 Evaluation Metrics:
Let TP = True Positives, FP = False Positives, TN = True Negatives, FN = False Negatives.

  - Precision (Positive Predictive Value):  P = TP / (TP + FP)
  - Recall (Sensitivity / True Positive Rate): R = TP / (TP + FN)
  - F1-Score:                               F1 = 2 * (P * R) / (P + R)
  - Accuracy:                               Acc = (TP + TN) / (TP + TN + FP + FN)
  - True Positive Rate:                     TPR = TP / (TP + FN)
  - False Positive Rate:                    FPR = FP / (FP + TN)

  - Precision-Recall AUC (PR-AUC / Average Precision):
    PR-AUC = sum_{k} (R_k - R_{k-1}) * P_k
    Crucial metric: Random guessing baseline = Positive Prevalence = 6 / 394 = 0.0152.

  - Receiver Operating Characteristic AUC (ROC-AUC):
    ROC-AUC = integral_0^1 TPR(FPR) d(FPR)

9.3 Scientific Findings & Comparative Analysis:
  1. BDH v4 is the Superior Flare Detection Architecture:
     BDH v4 achieves the highest PR-AUC of 0.0451, which is approximately 3.0x 
     higher than the no-skill random baseline (0.0152). Its multi-scale causal 
     filters successfully capture multi-cadence chromospheric brightening precursors 
     that LSTM and TFT smooth out. At its optimal early-warning threshold (tau = 0.20), 
     BDH correctly warns of 50.0% of oncoming test flares (3 out of 6).

  2. LSTM Represents the Most Reliable Low-False-Alarm Baseline:
     LSTM excels in ROC-AUC (0.6783) and F1-score (0.0727), generating only 47 false 
     alarms on the test set compared to 187 for BDH. However, this conservativeness 
     results in missing 66.7% of flares (Recall = 33.3%).

  3. TFT Suffers From Over-Parameterization on Observational Regimes:
     With 237,577 parameters, TFT exhibited significant capacity mismatch for the 
     1,778 training sequences. Its variable selection and self-attention layers 
     overfit to background solar quiet oscillations, yielding the lowest PR-AUC (0.0209).
