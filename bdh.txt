1. WHAT IS BABY DRAGON HATCHLING (BDH)?
--------------------------------------------------------------------------------
1.1 Conceptual Identity & Origin:
Baby Dragon Hatchling (BDH) is a custom-engineered, multi-scale deep learning 
neural network designed specifically for temporal sequence forecasting of rare, 
high-impact solar events (solar flares and coronal mass ejections). 

The metaphorical name "Baby Dragon Hatchling" originates from solar physics:
- Solar flares and eruptive coronal mass ejections are often metaphorically described 
  by astrophysicists as "solar dragons" due to their serpentine magnetic filament 
  structures and breath of high-energy plasma.
- The "Hatchling" phase represents the earliest nascent pre-flare phase (the initial 
  magnetic reconnection and localized chromospheric brightening occurring 30 to 
  90 seconds prior to GOES X-ray onset).
- BDH was engineered specifically to detect these subtle initial "sparks" before 
  the full flare erupts.

1.2 Core Architectural Philosophy:
Standard sequence models like Recurrent Neural Networks (RNN/LSTM) process frames 
step-by-step with a fixed memory vector, which tends to saturate or forget distant 
baseline conditions. Conversely, standard Transformers compute quadratic all-to-all 
self-attention, which severely overfits when training on small astronomical event 
samples (such as 32 independent flare events).

BDH bridges this gap by combining three complementary temporal inductive biases:
1. Multi-Scale 1D Convolutions: Parallel temporal receptive fields that capture 
   micro-spikes (3 frames), intermediate flux emergence (7 frames), and slow 
   thermal buildup (15 frames) simultaneously.
2. Dilated Gated Residual Blocks with Squeeze-and-Excitation (SE): Deep non-linear 
   feature mixing across exponentially growing dilation factors (2^0, 2^1, 2^2) 
   with channel-wise adaptive recalibration.
3. Strictly Causal Padding & Temporal Recency-Biased Attention Pooling: Absolute 
   prevention of future data leakage, paired with an explicit linear gradient 
   biasing attention toward the critical T-0 horizon frames.

3. END-TO-END DATA PROCESSING & TENSOR FLOW
--------------------------------------------------------------------------------
The end-to-end data processing pipeline through BDH proceeds through 8 distinct 
stages:

STAGE 1: Raw Observation Ingestion (FITS Level 1.0)
---------------------------------------------------
A sequence of 80 continuous FITS files from the Aditya-L1 SUIT NB04 Mg II h channel 
(280.3 nm) is loaded. Each file contains a 2D intensity array (e.g., 2048x2048 or 
sub-ROI 512x512).

STAGE 2: Statistical Feature Extraction
---------------------------------------
For each of the 80 frames, 18 active numerical features are computed:
  1. mean_dn               : Mean digital count across valid solar pixels
  2. std_dn                : Standard deviation of pixel counts
  3. min_dn                : Minimum count
  4. max_dn                : Maximum count
  5-11. p01, p10, p50, p90, p95, p99, p999 : Seven intensity percentiles
  12. skew_dn              : Pixel distribution skewness
  13. kurt_dn              : Pixel distribution excess kurtosis
  14. enhancement_ratio    : (p99 - p50) / std_dn (Relative flare core brightness)
  15. bright_pix_frac      : Fraction of pixels > p50 + 2*sigma
  16. exposure_s           : Exposure duration in seconds
  17. hpc_tx_center_arcsec : Solar Helioprojective Cartesian X centroid (arcsec)
  18. hpc_ty_center_arcsec : Solar Helioprojective Cartesian Y centroid (arcsec)

Output tensor shape: (T = 80, D = 18)

STAGE 3: Normalization & Outlier Suppression
-------------------------------------------
Using precomputed training-set parameters (stored in `models/preprocessing_params_v4.npz`):
  X_norm = clip( (X_raw - mu_train) / sigma_train, -5.0, 5.0 )
Output tensor shape: (B, 80, 18) where B is batch size (B=1 for single sequence).

STAGE 4: Linear Feature Embedding
---------------------------------
Each 18-dim vector is linearly projected to hidden dimension d_h = 64, followed 
by Layer Normalization and GELU activation:
  h_0(t) = GELU( LayerNorm( W_in * x(t) + b_in ) )
Output tensor shape: (B, 80, 64). Transposed to (B, 64, 80) for 1D convolutions.

STAGE 5: Multi-Scale Causal Temporal Convolutions
------------------------------------------------
The tensor passes through 3 parallel causal convolution branches:
  Branch 1: kernel_size = 3,  out_channels = 21 (Captures 3-minute impulsive spikes)
  Branch 2: kernel_size = 7,  out_channels = 21 (Captures 7-minute thermal growth)
  Branch 3: kernel_size = 15, out_channels = 22 (Captures 15-minute magnetic emergence)
Concatenated along channel axis (21 + 21 + 22 = 64), normalized by GroupNorm(8, 64), 
and passed through GELU activation.
Output tensor shape: (B, 64, 80).

STAGE 6: Dilated Gated Residual Blocks with Squeeze-and-Excitation
-----------------------------------------------------------------
Passes through M = 3 sequential residual blocks with dilations d in {1, 2, 4}:
- Filter branch: CausalConv1D(kernel=3, dilation=d) -> tanh
- Gating branch: CausalConv1D(kernel=3, dilation=d) -> sigmoid
- Element-wise product: Gated Linear Unit (GLU)
- Channel Squeeze-and-Excitation: Global Average Pooling -> Linear(64->16) -> ReLU -> 
  Linear(16->64) -> sigmoid -> channel recalibration
- Residual skip connection: output = input + gated_features * se_weights
Output tensor shape: (B, 64, 80). Transposed back to (B, 80, 64).

STAGE 7: Temporal Attention Pooling with Learnable Recency Bias
--------------------------------------------------------------
Calculates attention weight alpha(t) for every frame t in {1, ..., 80}:
  logit(t) = w_attn^T * LayerNorm( h(t) ) + beta * pos(t)
where pos(t) = (t-1)/79 in [0.0, 1.0], and beta is a learnable scalar (init=1.2).
  alpha(t) = softmax( logit(t) )
  z = sum_{t=1}^80 alpha(t) * h(t)
Output tensor shape: (B, 64) [Collapsed across temporal dimension].

STAGE 8: Classification MLP & Probability Output
------------------------------------------------
Pooled representation z is fed into a 2-layer MLP:
  z_dense = Dropout(0.30)( GELU( LayerNorm( W_1 * z + b_1 ) ) )   [64 -> 32]
  logit   = W_2 * z_dense + b_2                                  [32 -> 1]
  prob    = sigmoid( logit ) in [0.0, 1.0]
If prob >= 0.200 (optimal calibrated decision threshold):
  Decision: "FLARE LIKELY" (Onset anticipated within next 90 seconds)
Else:
  Decision: "No Flare"


4. MATHEMATICAL SPECIFICATION OF ALL BDH MODULES
--------------------------------------------------------------------------------

4.1 Causal Convolution 1D (CausalConv1d):
Standard 1D convolution with symmetric padding leaks future timesteps into the 
receptive field of the current timestep. To ensure strict physical causality:
Given input x in R^{B x C_in x T}, kernel size k, and dilation d:
  Left-sided padding length: P = (k - 1) * d
  x_padded = Pad_left(x, P)  in R^{B x C_in x (T + P)}
  y = Conv1d_{no_pad}( x_padded ) in R^{B x C_out x T}
Mathematical definition at timestep t:
  y_j(t) = sum_{c=1}^{C_in} sum_{i=0}^{k-1} W_{j, c, i} * x_c(t - i * d) + b_j
Notice that y_j(t) depends solely on inputs x(t), x(t-d), ..., x(t - (k-1)d). 
It NEVER accesses x(t + tau) for any tau > 0.

4.2 Multi-Scale Causal Convolution (MultiScaleCausalConv):
Let C_out = 64. Channels are partitioned as:
  C_1 = 64 // 3 = 21
  C_2 = 64 // 3 = 21
  C_3 = 64 - 2 * 21 = 22
Parallel operations:
  c_3(t)  = CausalConv1d(k=3,  d=1, out=21)(x)
  c_7(t)  = CausalConv1d(k=7,  d=1, out=21)(x)
  c_15(t) = CausalConv1d(k=15, d=1, out=22)(x)
Concatenation & Group Normalization:
  c_cat = [c_3(t) || c_7(t) || c_15(t)] in R^{B x 64 x T}
  y = GELU( GroupNorm(num_groups=8, num_channels=64)(c_cat) )

4.3 Gated Causal Residual Block (GatedCausalResidualBlock):
For residual block with channel depth C = 64 and dilation factor d:
1. Gated Activation:
   f(t) = tanh( CausalConv1d(k=3, d=d)(x) )     [Hyperbolic tangent filter]
   g(t) = sigmoid( CausalConv1d(k=3, d=d)(x) )  [Sigmoid information gate]
   h(t) = Dropout_{0.30}( GroupNorm_8( f(t) (x) g(t) ) )
2. Squeeze-and-Excitation (SE) Channel Attention:
   s = (1 / T) * sum_{t=1}^T h(t)  in R^C       [Global Average Pooling]
   r = max(C // 4, 4) = 16                      [Bottleneck dimension]
   e = sigmoid( W_2 * ReLU( W_1 * s ) )         [Channel excitation vector]
   where W_1 in R^{16 x 64}, W_2 in R^{64 x 16}
3. Residual Sum:
   out(t) = x(t) + h(t) (x) e

4.4 Temporal Attention Pooling with Learnable Recency Bias:
Given hidden representations H = [h_1, ..., h_T] in R^{T x 64}:
1. Recency Position Index:
   pos(t) = (t - 1) / (T - 1) in [0.0, 1.0]     (pos=0 at start, pos=1 at horizon)
2. Attention Logits:
   a(t) = w_attn^T * LayerNorm( h(t) ) + beta * pos(t)
   where w_attn in R^{64 x 1} (bias-free linear projection)
   beta in R is a learnable parameter initialized to 1.2
3. Normalized Softmax Weights:
   alpha(t) = exp( a(t) ) / sum_{t'=1}^T exp( a(t') )
4. Context Pooling:
   z = sum_{t=1}^T alpha(t) * h(t) in R^{64}

4.5 Classification Head:
   z_1 = GELU( LayerNorm( W_c1 * z + b_c1 ) )     [W_c1 in R^{32 x 64}]
   z_drop = Dropout_{0.30}( z_1 )
   logit = W_c2 * z_drop + b_c2                   [W_c2 in R^{1 x 32}]
   Probability = 1 / (1 + exp(-logit))


5. INITIALIZATION & REPRODUCIBILITY PROTOCOL
--------------------------------------------------------------------------------
5.1 Weight Initialization:
- 1D Convolutional Kernels:
  Initialized using Kaiming Uniform (He normal initialization):
  W ~ Uniform( -sqrt(1 / k_in), sqrt(1 / k_in) )
  where k_in = in_channels * kernel_size.
- Linear Projection & MLP Layers:
  Initialized via Xavier / Glorot Uniform:
  W ~ Uniform( -sqrt(6 / (fan_in + fan_out)), sqrt(6 / (fan_in + fan_out)) )
- Normalization Layers (LayerNorm, GroupNorm):
  Affine scale gamma = 1.0, bias beta = 0.0.
- Recency Bias Parameter (beta):
  Initialized explicitly to a positive scalar:
  self.pos_bias = nn.Parameter(torch.tensor(1.2))
  This provides an inductive prior that recent frames contain higher pre-flare 
  entropy than distant frames, while allowing gradient descent to adjust or invert 
  this bias if needed.

6. TRAINING ENGINE & HYPERPARAMETERS
--------------------------------------------------------------------------------
6.1 Loss Function Formulation:
Solar flare forecasting suffers from extreme class imbalance (positive prevalence 
in authentic data is only 1.57%). Standard unweighted BCE causes gradient starvation 
for the positive class, resulting in a degenerate model that predicts 0 for all frames.

BDH is trained using Class-Weighted Binary Cross-Entropy with Logits:
  pos_weight = N_negative_train / N_positive_train = 1750 / 28 = 62.50

  L(y, logit) = - (1 / B) * sum_{i=1}^B [
      62.50 * y_i * log( sigmoid(logit_i) ) + (1 - y_i) * log( 1 - sigmoid(logit_i) )
  ]

6.2 Optimizer & Scheduler:
  - Optimizer:           AdamW (Loshchilov & Hutter)
  - Base Learning Rate:  eta_0 = 3e-4 (0.0003)
  - Weight Decay:        lambda = 1e-4 (0.0001)
  - Batch Size:          B = 64
  - Training Epochs:     40 epochs
  - Gradient Clipping:   ||g||_2 <= 3.0 (Maximum L2 gradient norm)
  - Learning Rate Decay: Cosine Annealing:
                         eta(epoch) = 1e-5 + 0.5 * (3e-4 - 1e-5) * (1 + cos(pi * epoch / 40))

6.3 Model Selection Criterion:
Rather than checkpointing on minimum training loss (which rewards memorizing negative 
background frames), BDH checkpoints are selected strictly on the maximum 
Precision-Recall AUC (PR-AUC / Average Precision) on the independent Validation Set 
(518 sequences, 8 positives, 7 flares).


7. INFERENCE & CALIBRATED DECISION THRESHOLDS
--------------------------------------------------------------------------------
7.1 Why Not Standard 0.5 Threshold?
In high-imbalance binary classification where the loss was scaled by pos_weight = 62.5, 
uncalibrated sigmoid probabilities will naturally reflect the shifted loss distribution. 
Using a rigid 0.50 threshold is sub-optimal for early warning.

7.2 Calibrated Optimal Threshold:
During validation evaluation, the precision-recall curve is evaluated across 
1,000 threshold steps in [0.01, 0.99] to determine the threshold that maximizes 
the F1-score for flare early warning:
  - BDH v4 Optimal Threshold: tau* = 0.200

7.3 Operational Decision Rules:
  P(flare | X) >= 0.200  --> Class 1: "FLARE LIKELY" (Pre-flare early warning triggered)
  P(flare | X) <  0.200  --> Class 0: "No Flare" (Quiescent / background solar activity)

9. COMPLETE SELF-CONTAINED PYTORCH SOURCE CODE FOR BDH v4
--------------------------------------------------------------------------------
The following code represents the exact, fully operational implementation of 
Baby Dragon Hatchling v4 as deployed in `scripts/rebuild_step4_train_models.py` 
and `app.py`:

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class CausalConv1d(nn.Module):
    """
    1D Convolution with strict left-sided causal padding.
    Ensures output at timestep t depends strictly on inputs at <= t.
    """
    def __init__(self, in_ch, out_ch, kernel_size, dilation=1):
        super().__init__()
        self.pad = (kernel_size - 1) * dilation
        self.conv = nn.Conv1d(in_ch, out_ch, kernel_size, dilation=dilation)

    def forward(self, x):
        # Pad left by (kernel_size - 1) * dilation, pad right by 0
        return self.conv(F.pad(x, (self.pad, 0)))


class MultiScaleCausalConv(nn.Module):
    """
    Multi-Scale Causal Convolutional Branch.
    Extracts impulsive (k=3), intermediate (k=7), and slow (k=15) solar dynamics.
    """
    def __init__(self, in_ch, out_ch):
        super().__init__()
        third = out_ch // 3
        rem   = out_ch - 2 * third
        self.conv3  = CausalConv1d(in_ch, third, 3)
        self.conv7  = CausalConv1d(in_ch, third, 7)
        self.conv15 = CausalConv1d(in_ch, rem,   15)
        self.norm   = nn.GroupNorm(min(8, out_ch), out_ch)
        self.act    = nn.GELU()

    def forward(self, x):
        c3  = self.conv3(x)
        c7  = self.conv7(x)
        c15 = self.conv15(x)
        return self.act(self.norm(torch.cat([c3, c7, c15], dim=1)))


class GatedCausalResidualBlock(nn.Module):
    """
    Dilated Gated Residual Block with Channel Squeeze-and-Excitation (SE).
    """
    def __init__(self, ch, dilation=1, dropout=0.30):
        super().__init__()
        self.conv_f = CausalConv1d(ch, ch, 3, dilation=dilation)
        self.conv_g = CausalConv1d(ch, ch, 3, dilation=dilation)
        self.norm   = nn.GroupNorm(min(8, ch), ch)
        self.drop   = nn.Dropout(dropout)
        r           = max(ch // 4, 4)
        self.se1    = nn.Linear(ch, r)
        self.se2    = nn.Linear(r, ch)

    def forward(self, x):
        # Gated Linear Unit
        h  = torch.tanh(self.conv_f(x)) * torch.sigmoid(self.conv_g(x))
        h  = self.drop(self.norm(h))
        # Channel-wise Squeeze-and-Excitation
        se = torch.sigmoid(self.se2(F.relu(self.se1(h.mean(-1))))).unsqueeze(-1)
        return x + h * se


class BabyDragonHatchlingV4(nn.Module):
    """
    Baby Dragon Hatchling (BDH v4):
    Input Projection -> Multi-Scale Causal Convolutions -> 
    Dilated Gated Residual Blocks -> Temporal Positional-Biased Attention Pooling ->
    Classification Head.
    """
    def __init__(self, in_features=18, hidden_dim=64, num_blocks=3, dropout=0.30):
        super().__init__()
        self.in_proj = nn.Sequential(
            nn.Linear(in_features, hidden_dim),
            nn.LayerNorm(hidden_dim),
            nn.GELU()
        )
        self.multiscale = MultiScaleCausalConv(hidden_dim, hidden_dim)
        self.blocks = nn.ModuleList([
            GatedCausalResidualBlock(hidden_dim, dilation=2**i, dropout=dropout)
            for i in range(num_blocks)
        ])
        self.attn_q   = nn.Linear(hidden_dim, 1, bias=False)
        self.attn_n   = nn.LayerNorm(hidden_dim)
        self.pos_bias = nn.Parameter(torch.tensor(1.2))  # Learnable recency bias

        self.classifier = nn.Sequential(
            nn.Linear(hidden_dim, 32),
            nn.LayerNorm(32),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(32, 1)
        )

    def forward(self, x):
        # Input x shape: (Batch, Seq_Len=80, Features=18)
        h = self.in_proj(x).transpose(1, 2)  # Shape: (Batch, Hidden=64, Seq_Len=80)
        h = self.multiscale(h)
        for blk in self.blocks:
            h = blk(h)
        h = h.transpose(1, 2)                # Shape: (Batch, Seq_Len=80, Hidden=64)

        # Temporal Positional-Biased Attention Pooling
        T = h.size(1)
        pos = torch.linspace(0.0, 1.0, T, device=x.device).unsqueeze(0).unsqueeze(-1)
        attn_logits = self.attn_q(self.attn_n(h)) + self.pos_bias * pos
        attn_weights = torch.softmax(attn_logits, dim=1)
        pooled = (h * attn_weights).sum(dim=1)  # Shape: (Batch, Hidden=64)

        return self.classifier(pooled)          # Logit shape: (Batch, 1)
```
